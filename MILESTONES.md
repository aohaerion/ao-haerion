# AO Haerion Milestones

This file tracks the first public milestone structure for AO Haerion.

The milestones below are documentation and design milestones unless explicitly stated otherwise.

## Status legend

| Status | Meaning |
|---|---|
| Proposed | A candidate milestone currently being shaped. |
| Draft | Documentation exists but is not final or baseline. |
| Future exploration | A possible future direction with no stable scope yet. |
| Baseline | A reviewed and accepted reference state. Not currently used here. |

## M001 — Governed Memory Layer

**Status:** Proposed public design milestone  
**Type:** Documentation and design  
**Public state:** Non-baseline

### Goal

Define how AO Haerion preserves context, decisions, evidence, and direction across interrupted work.

### Expected outputs

- A public explanation of governed memory.
- A clear distinction between preserved and non-preserved material.
- A basic flow for resuming interrupted work.
- A list of risks, limits, and non-goals.
- A human-readable glossary for key terms.

### Non-goals

M001 does not aim to provide:

- a complete AO Haerion system;
- a working runtime implementation;
- autonomous execution;
- full project governance;
- private memory infrastructure;
- a universal knowledge base;
- automatic truth validation.

See: [docs/m001-governed-memory-layer.md](docs/m001-governed-memory-layer.md)
