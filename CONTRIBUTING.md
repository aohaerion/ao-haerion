# Contributing to AO Haerion

AO Haerion is currently in a **public documentation draft** phase.

At this stage, contributions should help improve clarity, traceability, and public understanding of the project.

## Current scope

The current public focus is:

- AO Haerion public foundation;
- M001 — Governed Memory Layer;
- documentation, terminology, and public explanation.

## Good contributions

Useful contributions include:

- fixing typos;
- improving readability;
- clarifying ambiguous wording;
- improving links or document structure;
- proposing small documentation improvements;
- opening issues about unclear concepts;
- identifying possible overclaim.

## Out of scope for now

Please do not submit contributions that:

- present AO Haerion as a complete system;
- claim runtime or production-ready status;
- promote draft material to baseline;
- expand this repository into unrelated AO, APR, KSP, MAPS, AO-Router, or Aetherion Omniversus material;
- add large implementation proposals without prior discussion;
- use AO Haerion name, logo, or visual identity for derivative projects without permission.

## How to contribute

For now, please start with an issue before opening a pull request.

Use clear language and explain:

- what document or section you are referring to;
- what is unclear, incomplete, or risky;
- what change you propose;
- why the change helps the public documentation.

## Public status

All material remains documentation draft unless explicitly stated otherwise.

No baseline is declared by contribution alone.

No runtime implementation is claimed by contribution alone.
