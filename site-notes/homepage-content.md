## Proposed section

### Current technical milestone — M001 Governed Memory Layer

AO Haerion is starting from a first public technical design milestone:

**M001 — Governed Memory Layer**

M001 defines how AO Haerion preserves context, decisions, evidence, and direction across interrupted work.

The goal is simple:

when a path is interrupted, returning to it should not depend on memory alone.

M001 is currently a public documentation and design milestone.
It is not a complete system, not a production runtime, and not a baseline.

Read more in the repository:

- `ROADMAP.md`
- `MILESTONES.md`
- `docs/m001-governed-memory-layer.md`
